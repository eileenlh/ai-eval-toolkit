# The AI Reality Check

An interactive research guide for evaluating AI-generated information with the **Library AI Evaluation Framework (LAEF)**. The guide helps users triage claims, verify source–claim fit, cross-reference evidence, stress-test model behavior, and make accountable decisions about AI outputs.

## View the guide

Open `index.html` locally or publish it with GitHub Pages.

## Publish with GitHub Pages

1. Place `index.html` in the repository root.
2. In GitHub, open **Settings → Pages**.
3. Select the repository branch and root folder, then save.

## Update the content

Use `editor-private.html` locally to revise text and download an updated page. Replace `index.html` with the downloaded file and commit the change. Do not publish `editor-private.html`; the public `index.html` is read-only.

## Framework source

The guide is adapted from the AI evaluation workshop and the *AI Output Evaluation, Zotero Synthesis, and LAEF Three-Layer Mapping* research synthesis.
